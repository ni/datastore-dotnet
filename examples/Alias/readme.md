# Alias Example

This example demonstrates how to create and use aliases to more easily refer to metadata entities, like operators.

## Running this example

1. Open a command prompt and navigate to `<datastore-dotnet>/examples`.
2. Build the examples by running `dotnet build`
3. Execute the alias example by running `dotnet run Alias/Alias.csproj`

If you prefer, you can open `<datastore-dotnet>/examples/Examples.sln` in Microsoft Visual Studios and use the IDE
to build and run projects within the solution.
