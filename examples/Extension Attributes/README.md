# Extension Attributes Example

This example demonstrates how to specify extension attributes on metadata
objects. It also shows how to perform an oData query that filters on an extension attribute.

## Running this example

1. Open a command prompt and navigate to `<datastore-dotnet>/examples`.
2. Build the examples by running `dotnet build`
3. Execute the extension attributes example by running `dotnet run --project "Extension Attributes/Extension Attributes.csproj"`
