# Extension Attributes Example

This example demonstrates how to augment metadata entities using extension attributes. Extension attributes
are a dictionary of attribute names to attribute values. The expected extension attributes can be specified
in a schema file which is used to validate extension attributes on metadata items.

## Running this example

1. Open a command prompt and navigate to `<datastore-dotnet>/examples`.
2. Build the examples by running `dotnet build`
3. Execute the alias example by running `dotnet run Extension Attributes/Extension Attributes.csproj`

If you prefer, you can open `<datastore-dotnet>/examples/Examples.sln` in Microsoft Visual Studios and use the IDE
to build and run projects within the solution.
