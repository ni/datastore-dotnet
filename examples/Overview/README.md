# Overview Example

This example demonstrates basic functionality provided by Measurement Data Services.
* Creating DataStore and MetadataStore clients
* Creating data and metadata objects
* Validating metadata objects using a schema
* Using extension attributes to add custom properties to metadata objects
* Publishing and reading data

## Running this example

1. Open a command prompt and navigate to `<datastore-dotnet>/examples`.
2. Build the examples by running `dotnet build`
3. Execute the overview example by running `dotnet run --project Overview/Overview.csproj`
